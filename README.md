# AI Project Architect

The production deployment is one Docker web service and one public URL. FastAPI serves the Vite production build at `/` and the API at `/api/...`; React uses relative API paths, so the browser never needs a separate backend origin. The Render Blueprint also provisions PostgreSQL for durable projects, agent outputs, and workflow events.

## Deploy

1. Push this repository to GitHub.
2. In Render, create a Blueprint from the repository and apply `render.yaml`.
3. Set `OPENAI_API_KEY` and, optionally, `HUGGINGFACE_API_KEY` in the Render service environment. Secrets stay in the provider, not in source control.
4. Open the single URL assigned to the `ai-project-architect` web service. That URL serves the UI and every API route.

The Docker build runs `npm run build` for React, copies `frontend/dist` into the FastAPI image, and starts Uvicorn. Render connects the web service to the managed `architect-db` PostgreSQL database. Redeploy by pushing changes to the connected branch or selecting **Manual Deploy** in Render. Do not configure a separate static-site service.

LangChain prompt templates and structured-output chains power the agents when `OPENAI_API_KEY` is set. Hugging Face Sentence Transformers embeddings feed the architecture knowledge-base retriever used by those agents. Without model credentials or model access, the app degrades to deterministic agent output and the RAG module's offline retrieval fallback; configure the keys for hosted AI analysis.

## Local development

Use Node.js 20+ and Python 3.10+ for a setup compatible with the production image.

```sh
python3 -m venv .venv
. .venv/bin/activate
pip install -r backend/requirements.txt
npm install
npm run dev
```

Open `http://localhost:5173`. Vite proxies `/api` to FastAPI at `http://localhost:8000`. For a production-like local run:

```sh
npm run build
cd backend
../.venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000
```

Then open `http://localhost:8000`; the same server handles both the built frontend and API. Local storage defaults to SQLite (`architect.db` in the backend working directory).

## Environment

Copy `.env.example` to `.env` and set values as needed:

| Variable | Purpose |
| --- | --- |
| `OPENAI_API_KEY` | Enables LangChain ChatOpenAI agent calls |
| `LLM_MODEL` | Chat model name, defaults to `gpt-4o-mini` |
| `HUGGINGFACE_API_KEY` | Optional token for Hugging Face model access |
| `HUGGINGFACE_MODEL` | Embedding model alias when the specific setting is omitted |
| `HUGGINGFACE_EMBEDDING_MODEL` | Sentence Transformers model used for knowledge retrieval |
| `DATABASE_URL` | SQLAlchemy URL; local default is SQLite, Render supplies PostgreSQL |

Never place provider keys in frontend code. The deployed URL is generated by Render after the Blueprint is created; this workspace has not been deployed and therefore has no live production URL to report yet.
